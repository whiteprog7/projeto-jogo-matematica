# Histórico de versões — Tufi

A `main` contém a versão atual. Cada branch `versoes/v…` guarda uma etapa recuperada do histórico do projeto. Os números abaixo foram atribuídos na organização inicial no GitHub; todas são versões beta.

| Versão | Conteúdo | Código |
|---|---|---|
| 0.1.0-beta | Base do jogo: regiões, missões, turmas, ranking e histórico. | [Abrir versão](https://github.com/whiteprog7/projeto-jogo-matematica/tree/versoes/v0.1.0-beta) |
| 0.2.0-beta | Painel administrativo, aprovação de contas e correção do treino offline. | [Abrir versão](https://github.com/whiteprog7/projeto-jogo-matematica/tree/versoes/v0.2.0-beta) |
| 0.3.0-beta | Missões narrativas, progressão, conquistas, Livro do Explorador e indicadores pedagógicos. | [Abrir versão](https://github.com/whiteprog7/projeto-jogo-matematica/tree/versoes/v0.3.0-beta) |
| 0.4.0-beta | Entrada por perfil, cadastro com ID e senha, sessões e autorização pelo administrador. | [Abrir versão](https://github.com/whiteprog7/projeto-jogo-matematica/tree/versoes/v0.4.0-beta) |

As versões anteriores são referências históricas; use a versão atual para continuar o desenvolvimento. Elas não recebem automaticamente correções posteriores. O envio ao GitHub não altera o jogo publicado nem transfere seu banco de dados.

## 0.5.0-beta

[Abrir versão](https://github.com/whiteprog7/projeto-jogo-matematica/tree/versoes/v0.5.0-beta).
